# Smart Scorebook V2
Prototype ระบบสมุดคะแนนและเช็กชื่อแบบ Smart Classroom

## จุดเด่น V2
1. Teacher Dashboard
2. Student Mode เข้าห้องด้วย Class Code + เลขที่
3. สร้างห้องเรียนและรหัสห้อง
4. จัดการนักเรียน
5. เช็กชื่อ มา / สาย / ลา / ขาด
6. บันทึกคะแนนหลายกิจกรรม
7. วิเคราะห์คะแนน + การมาเรียน
8. Export CSV
9. Responsive
10. โครงสร้างข้อมูลแยก students/classes/assessments/scores/attendance เพื่อพร้อมต่อฐานข้อมูล
